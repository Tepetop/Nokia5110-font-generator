Instructions

  • Full Screen Mode: Display the entire Nokia 5110 screen (84x48 pixels)
  • Custom Size Mode: Display a portion of the screen with custom dimensions (default 6x8 for PCD8544 character design)
  • Spacing Border: Configure top/bottom/left/right separation; selected border zones are pink, always empty, and non-editable
  • Auto-Render Character: Type a character (A-Z, a-z, 0-9, symbols) and click "Render Character" to automatically display it
  • Render from HEX: Paste HEX bytes (e.g. 0x3E, 0x51, ...) to display a character from byte data; grid size is auto-fitted
  • Click on any square to toggle it between white and black
  • Clear All: Reset all pixels to white
  • Export Font Data: Generate byte array data for use in Arduino/C++ code
