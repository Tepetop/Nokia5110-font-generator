Nokia 5110 Font Generator - Example Usage

Quick Start: Open index.html in your web browser to start creating fonts!

Creating a Simple Character

  1. Open index.html in your browser
  2. Select "Custom Size" mode
  3. Set Width: 5, Height: 7 (common font size)
  4. Click "Apply Size"
  5. Click on squares to draw your character
  6. Click "Export Font Data"
  7. Copy the generated code

Arduino Example

Here's how to use the generated font data in your Arduino sketch:

// Include the Nokia 5110 library
#include <Adafruit_GFX.h>
#include <Adafruit_PCD8544.h>

// Pin configuration
Adafruit_PCD8544 display = Adafruit_PCD8544(7, 6, 5, 4, 3);

// Your custom character (generated from the font generator)
const unsigned char myChar[7] = {
  0x1F, 0x11, 0x11, 0x11, 0x1F, 0x00, 0x00
};

void setup() {
  display.begin();
  display.setContrast(50);
  display.clearDisplay();
  
  // Draw your custom character
  display.drawBitmap(0, 0, myChar, 5, 7, BLACK);
  
  display.display();
}

void loop() {
  // Your code here
}

Creating a Full Font Set

To create a complete font (A-Z, 0-9):

  1. Design each character in custom size mode (e.g., 5x7)
  2. Export each character's data
  3. Combine all characters into a single array
// Complete font array (example with just a few characters)
const unsigned char myFont[][7] = {
  // 'A'
  {0x1F, 0x11, 0x11, 0x11, 0x1F, 0x00, 0x00},
  // 'B'
  {0x1F, 0x15, 0x15, 0x15, 0x0A, 0x00, 0x00},
  // Add more characters...
};

// Function to draw a character
void drawChar(int x, int y, char c) {
  int index = c - 'A'; // Assuming A-Z
  if (index >= 0 && index < 26) {
    display.drawBitmap(x, y, myFont[index], 5, 7, BLACK);
  }
}

Tips and Tricks

  • Standard Font Size: 5x7 or 8x8 pixels work well for readable text
  • Large Characters: Use 8x6 or larger for better visibility
  • Full Screen Graphics: Use 84x48 mode for logos or images
  • Spacing: Leave at least 1 pixel between characters for readability
  • Testing: Test on actual hardware as screens may render differently

Common Font Sizes

  • 5x7: Standard small font
  • 6x8: Slightly larger, more readable
  • 8x8: Square pixels, good for icons
  • 8x12: Tall characters, very readable
Note: The Nokia 5110 LCD uses a 84x48 pixel monochrome display. Each pixel is either on (black) or off (white). The display organizes pixels in pages of 8 vertical pixels, which is why heights divisible by 8 use a different export format.
